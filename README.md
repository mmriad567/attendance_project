# উপস্থিতি ব্যবস্থাপনা সিস্টেম (Attendance Management System)

বাংলাদেশের পলিটেকনিক ইনস্টিটিউটের জন্য তৈরি একটি পূর্ণাঙ্গ অনলাইন হাজিরা ব্যবস্থাপনা সিস্টেম। এটি Django দিয়ে তৈরি, যেখানে অ্যাডমিন, শিক্ষক ও শিক্ষার্থী—তিনটি রোলের জন্য আলাদা সুবিধা রয়েছে। শিক্ষক ক্লাসের হাজিরা দেবেন, শিক্ষার্থী নিজের হাজিরার হিসাব দেখবেন, আর অ্যাডমিন পুরো প্রতিষ্ঠান পরিচালনা করবেন।

GitHub: https://github.com/mmriad567/attendance_project

---

## ১. বৈশিষ্ট্য (Features)

- **তিনটি রোল:** Admin, Teacher, Student — প্রত্যেকের আলাদা ড্যাশবোর্ড ও অনুমতি।
- **বিভাগ ও বিষয় ব্যবস্থাপনা:** ডিপার্টমেন্ট (CST, EEE, MEC), একাডেমিক সেশন (যেমন ২০২২-২০২৩), সেমিস্টারভিত্তিক বিষয় (BTEB কোড সহ), শিফট ও সেকশন।
- **ক্লাস সেশন ও হাজিরা:** শিক্ষক তারিখ, পিরিয়ড ও টপিক অনুযায়ী ক্লাস সেশন তৈরি করেন; HTMX দিয়ে পেজ রিলোড ছাড়াই দ্রুত হাজিরা (Present / Absent / Late / Excused) দেওয়া যায়।
- **সম্পাদনা উইন্ডো:** নির্দিষ্ট দিনের পর পুরোনো হাজিরা আর পরিবর্তন করা যায় না (ডিফল্ট ৩ দিন)।
- **শিক্ষার্থীর ড্যাশবোর্ড:** মোট ও বিষয়ভিত্তিক হাজিরা %, ইতিহাস, এবং কম হাজিরার সতর্কবার্তা।
- **রিপোর্ট ও অ্যানালিটিক্স:** Chart.js চার্ট (শিক্ষার্থীভিত্তিক %, স্ট্যাটাস ডিস্ট্রিবিউশন, ট্রেন্ড), ডিফল্টার তালিকা, **CSV ও PDF এক্সপোর্ট**।
- **নোটিফিকেশন:** ইন-অ্যাপ নোটিফিকেশন + ইমেইল (ডেভে কনসোলে দেখানো হয়)।
- **নিরাপত্তা:** রোলভিত্তিক অ্যাক্সেস কন্ট্রোল, .env দিয়ে সিক্রেট কী, সমস্ত ইউজার ইনপুট ভ্যালিডেশন।

## ৫. সেটআপ (প্রথমবার চালু করার নিয়ম)

টার্মিনালে প্রজেক্ট ফোল্ডারে গিয়ে ধাপে ধাপে কমান্ড দিন:

```bash
# ১) ভার্চুয়াল এনভায়রনমেন্ট তৈরি ও চালু
python3 -m venv .venv
source .venv/bin/activate

# ২) প্যাকেজ ইনস্টল
pip install -r requirements.txt

# ৩) এনভায়রনমেন্ট ফাইল তৈরি (.env)
cp .env.example .env

# ৪) ডেটাবেস তৈরি
python manage.py migrate

# ৫) ডেমো ডেটা লোড (বিভাগ, শিক্ষক, শিক্ষার্থী, বিষয়, হাজিরা)
python manage.py seed_demo

# ৬) Tailwind CSS বিল্ড
make css        # অথবা: ./tailwindcss -i static/css/input.css -o static/css/app.css --minify

# ৭) সার্ভার চালু
python manage.py runserver
```

তারপর ব্রাউজারে খুলুন: **http://127.0.0.1:8000/login/**

> একই LAN-এর অন্য ডিভাইস থেকে দেখতে: `http://<আপনার-IP>:8000/login/`

## ৭. ব্যবহারবিধি (কীভাবে ব্যবহার করবেন)

### (ক) অ্যাডমিনের কাজ

1. `admin / demo12345` দিয়ে লগইন করুন।
2. উপরে **Admin** লিংকে ক্লিক করে Django অ্যাডমিন প্যানেলে যান: `/admin/`
3. এখান থেকে যা করতে পারবেন:
   - **Departments:** নতুন বিভাগ যোগ/সম্পাদনা (CST, EEE ইত্যাদি)
   - **Academic sessions:** নতুন ব্যাচ/সেশন (যেমন ২০২৩-২০২৪)
   - **Users:** নতুন শিক্ষক বা শিক্ষার্থীর লগইন তৈরি
   - **Student / Teacher profiles:** রোল নম্বর, রেজিস্ট্রেশন নম্বর, সেমিস্টার, সেকশন ইত্যাদি
   - **Subjects:** বিষয় ও BTEB কোড যোগ
   - **Subject offerings:** কোন বিষয় কোন সেশনে কোন শিক্ষক পড়াবেন তা নির্ধারণ
   - **Enrollments:** শিক্ষার্থীকে বিষয়ে ভর্তি করা (Offering-এর ভেতরে inline)
   - **Class sessions / Attendance records:** হাজিরা দেখা ও সম্পাদনা (রিড-অনলি রিপোর্টসহ)

### (খ) শিক্ষকের কাজ (হাজিরা দেওয়া)

1. `teacher.rahim / demo12345` দিয়ে লগইন করুন — সরাসরি **Teacher Dashboard**-এ যাবেন।
2. **Your subjects** তালিকায় আপনার বিষয়গুলো দেখবেন। যেকোনো বিষয়ের পাশে **New session** বাটনে ক্লিক করুন।
3. খোলা উইন্ডোতে দিন:
   - **Date:** আজ বা আগের কোনো তারিখ (৩ দিনের মধ্যে)
   - **Period No:** ক্লাসের পিরিয়ড
   - **Start/End time:** (ইচ্ছা)
   - **Topic:** ঐ দিনের পাঠ (ইচ্ছা)
4. **Start session** চাপলে ঐ বিষয়ের সব শিক্ষার্থীর জন্য হাজিরা পেজ খুলবে (ডিফল্টে সবাই Absent)।
5. প্রতিটি শিক্ষার্থীর পাশে **Present / Absent / Late / Excused** বাটনে ক্লিক করুন — প্রতিটি ক্লিক সাথে সাথে সেভ হয়ে যায় (HTMX, পেজ রিলোড লাগে না)।
6. সবাই উপস্থিত হলে উপরে **Mark all present** বাটন চাপুন।
7. **রিপোর্ট দেখতে:** উপরের Navbar থেকে **Reports** → বিষয় নির্বাচন করুন। এখানে চার্ট, শিক্ষার্থীভিত্তিক %, **Defaulters** তালিকা, **Export CSV**, **Export PDF** পাবেন।

> নোট: ৩ দিনের (ডিফল্ট) চেয়ে পুরোনো সেশনের হাজিরা আর সম্পাদনা করা যায় না — নিরাপত্তার জন্য।

### (গ) শিক্ষার্থীর কাজ

1. `student.2022001 / demo12345` দিয়ে লগইন করুন।
2. **My attendance** পেজে দেখবেন:
   - **Overall attendance %** (সবুজ = ঠিক আছে, লাল = থ্রেশহোল্ডের নিচে)
   - কতটি ক্লাস হয়েছে ও কতটিতে উপস্থিত ছিলেন
   - **By subject:** প্রতিটি বিষয়ের Present / Late / Absent ও %
   - কম হাজিরা হলে উপরে লাল **Low attendance warning**
3. **History** পেজে প্রতিটি ক্লাসের তারিখ, পিরিয়ড, বিষয় ও স্ট্যাটাস দেখতে পারবেন; বিষয় বা স্ট্যাটাস দিয়ে ফিল্টার করা যায়।
4. নোটিফিকেশন এলে উপরের **Notifications** বেল-এ সংখ্যা দেখাবে।

## ৮. ম্যানেজমেন্ট কমান্ড

```bash
# ডেমো ডেটা তৈরি (বারবার চালানো নিরাপদ — ডুপ্লিকেট হবে না)
python manage.py seed_demo

# কম হাজিরার শিক্ষার্থীদের নোটিফিকেশন ও ইমেইল পাঠানো
python manage.py check_attendance           # ইমেইলসহ
python manage.py check_attendance --no-email  # শুধু ইন-অ্যাপ নোটিফিকেশন

# নতুন অ্যাডমিন তৈরি (ইচ্ছা হলে)
python manage.py createsuperuser
```

> **নোট:** `check_attendance` কমান্ডটি একজন শিক্ষার্থীর কোনো নোটিফিকেশন না থাকলে নতুন ওয়ার্নিং তৈরি করে (ডুপ্লিকেট এড়ায়)। আসল ইমেইল পাঠাতে `.env`-এ SMTP সেটিংস দিতে হবে; ডিফল্টে ইমেইল টার্মিনালে (console) দেখাবে।

## ১০. সেটিংস পরিবর্তন (.env ফাইল)

`.env` ফাইলে যা যা পরিবর্তন করতে পারবেন:

| কী | অর্থ | ডিফল্ট |
|----|------|--------|
| `SECRET_KEY` | Django নিরাপত্তা কী | (নিজে দিন) |
| `DEBUG` | ডেভ মোড | `True` |
| `ALLOWED_HOSTS` | কোন হোস্ট থেকে অ্যাক্সেস | `127.0.0.1,localhost` |
| `INSTITUTE_NAME` | হেডারে দেখানো প্রতিষ্ঠানের নাম | `Polytechnic Institute` |
| `ATTENDANCE_THRESHOLD` | ন্যূনতম পাস হাজিরা % | `60` |
| `ATTENDANCE_EDIT_WINDOW_DAYS` | হাজিরা সম্পাদনার সময়সীমা (দিন) | `3` |

সেটিংস বদলানোর পর সার্ভার রিস্টার্ট করুন।

## ১১. প্রোডাকশনে নেওয়ার আগে (পরামর্শ)

- `DEBUG=False` করুন এবং একটি শক্তিশালী `SECRET_KEY` দিন।
- `ALLOWED_HOSTS`-এ আসল ডোমেইন যোগ করুন।
- `python manage.py collectstatic` চালান ও একটি স্ট্যাটিক ফাইল সার্ভার ব্যবহার করুন।
- SQLite-এর বদলে PostgreSQL ব্যবহার করা ভালো।
- আসল ইমেইল পাঠাতে SMTP (যেমন Gmail) সেটিংস `.env`-এ কনফিগার করুন।
